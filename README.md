# QQ 定时群发

这是一个给 Codex 用的个人 skill：在 QQ 电脑版里，按间隔重复发送同一条群消息，支持 @ 某人，并在对方回复后停止。

## 这个 skill 会做什么

- 先在输入框里做出一条完整消息：蓝色 @ 标签 + 正文，同一行
- 发送前先全选复制，后面每轮直接粘贴发送，避免 @ 和正文被拆成两条
- 按你定的间隔继续发
- 被 @ 的人回复后，或到时间/次数上限后停止

## 安装到 Codex

把这个仓库里的文件放到本机：

`%USERPROFILE%\.codex\skills\qq-repeat-send\`

需要包含：

- `SKILL.md`
- `agents/openai.yaml`

放好后，下一轮对话里就可以直接说：在某某群里每隔一分钟给某人发某某内容。

## 使用时请一次说清

- 群名或好友名
- 要发送的原文
- 要 @ 的准确昵称（如果需要）
- 间隔，以及持续多久或最多发几条
- 什么时候停，例如对方回复就停

没有授权的内容不会替你编，也不会自己加后缀。
